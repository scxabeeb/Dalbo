# Original DANXALIYE artwork

Source: owner-supplied `DANXALIYE_Logo_High_Quality-2.pdf` (Desktop/Dalbo).

The PDF contains one 4608×2304 RGB image. `danxaliye-logo-original.png` is that embedded image, extracted without redrawing. The full logo is used in web and Flutter. Native launchers use a crop of the symbol above the wordmark, placed on white and resized for platform requirements. Source colors/texture and internal white areas are retained.

Run `scripts/prepare-danxaliye-assets.py` with Pillow installed to regenerate derived assets. The previous code-generated DX monogram has been replaced.
