# DANXALIYE mobile

Flutter app with Somali service discovery, the 16-service catalog, private job photos, Hadda/Maanta/Berri request preferences, Mobile Money/Cash preference, status tracking, customer edit/cancel, and assigned-professional status updates. Legacy directory/chat/appointments remain accessible under Akoonka.

See the project root README for backend/database setup and `--dart-define=API_URL=...` configuration. Android debug cleartext is local-development only. Production requires HTTPS and signing. The high-quality logo is pending; the active native DX monogram is interim.
